# TRAVEL(여행플랫폼)
# 개요
 + SpringBootFramework를 이용한 여행 예약 사이트
## 만든 목적
 + 한 웹사이트안에서 자유여행과 패키지여행을 모두 예약할 수 있고 예약한 내용을 캘린더를 통해서 볼 수 있을면 좋지 않을까? 라는 생각을 가지게 되어 만들게 되었습니다.

## 일정
 + 7월1일 기획 및 피그마 설계
 + 7월2일 웹 디자인 완료 및 ERD설계
 + 7월3일 ~ 7월 6일 프론트 개발 완료
 + 7월7일 ~ 7월 15일 백엔드 개발완료

## 맡은 부분
 + 회원가입/로그인/로그아웃 기능 개발
   + session에 정보를 저장하여 로그인 및 로그아웃을 진행하였습니다
 + 마이페이지 개발
   + 구매한 상품의 리스트를 조회할 수 있습니다 
   + 자신의 정보를 수정할 수 있도록 제작하였습니다
   + 비밀번호를 수정할 때에는 DB 현재 사용하고 있는 비밀번호를 먼저 확인한 후 새로운 비밀번호로 수정할 수 있도록 제장하였습니다
 + 사이트 내 기업 관리자 페이지 개발
   + 상품을 등록하고 자사 상품을 구매한 구매이력을 확인할 수 있는 페이지를 제작하였습니다
 + 최고 관리자 페이지 개발
   + 회원/기업/상품/결제 정보를 확인 및 select을 통해 정보를 조회할 수 있는 기능을 제작하였습니다
